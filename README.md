# 🔌 ГЛАВЦИФРА — Спецификация API Интеграции v1.0 (OEM)

Данная документация предназначена для инженеров и разработчиков заводов-изготовителей шкафов управления (ШУН) и акустических логгеров. Протокол описывает формат передачи высокочастотного стриминга данных в облачное вычислительное ядро «ГЛАВЦИФРА».

## 🛰 Протокол передачи данных (MQTT / WebSockets)

Данные от датчиков тока (метод ESA) и акустических сенсоров должны упаковываться контроллером в JSON-пакет и отправляться методом `POST` на защищенный эндпоинт `https://glavcifra.ru` или через брокер MQTT.

### Пример валидного криптозащищенного пакета:

```json
{
  "device_id": "LOGGER-01-NOVOROS",
  "timestamp": 1787672520,
  "nonce": 101,
  "security_flag": "OK",
  "payload": [0.012, -0.045, 0.122, 0.089, -0.011, 0.054],
  "signature": "8b7a69f4c3d2e1a0b5c6d7e8f9a0b1c2d3e4f5a6b7c8d9e0f1a2b3c4d5e6f7a8"
}
```

### Описание полей спецификации:

*   `device_id` (string): Уникальный аппаратный идентификатор шкафа или логгера.
*   `timestamp` (int): Время формирования пакета на контроллере (Unix Epoch Time).
*   `nonce` (int): Монотонно возрастающий счетчик пакетов для защиты от атак повтора (Anti-Replay).
*   `security_flag` (string): Флаг модуля аппаратной защиты Anti-Tamper. Принимает значения: `OK`, `TAMPER_OPEN` (вскрытие корпуса), `JTAG_DETECTED` (подключение программатора).
*   `payload` (array of floats): Векторизованный массив сырых амплитуд акустического шума со стенки трубы или токовых гармоник.
*   `signature` (string): Криптографический проверочный ключ `HMAC-SHA256(Payload + Nonce, Secret_Salt)` для верификации подлинности устройства.
